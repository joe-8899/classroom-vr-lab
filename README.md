# 课堂练习室｜VR课堂管理培训

INT6141 第五组课堂管理培训方案交互演示。使用预设课堂脚本，支持学员回应、导师选择学生反应、回放标注、再次练习、两轮对照与行动计划。

网页： https://joe-8899.github.io/classroom-vr-lab/

## 访问与运行

网页公开访问，无需登录。也可下载后打开 index.html；三个文件须保留在同一文件夹。

## 演示边界

本网页是课程方案原型，未连接真实头显、麦克风或自动评分服务。学生反应为预设脚本，不代表真实培训结果。练习记录在访客浏览器处理；只有点击保存后，行动计划才保存在该访客本机，不会上传至服务器。
